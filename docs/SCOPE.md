# 프로젝트 범위

## 최종 목표

고정된 작업대에 임의로 구겨져 놓인 nominal 300×300 mm 정사각형 수건 한
장을 양팔로 펼치고, 서로 직교하는 두 중심선을 따라 두 번 접어 nominal
150×150 mm 정사각형으로 만든다.

## 포함

- nominal 300×300 mm인 등록된 정사각형 수건 한 장
- RGB 또는 RGB-D 기반 수건 mask, 높이, 경계와 grasp 후보 추정
- 들어 올리기, 장력 펼치기, 제한된 털기, corner drag와 lay-flat
- 네 모서리 복원, 평탄도 판정과 작업대 축 정렬
- 첫 번째 반 접기와 직교 방향 두 번째 반 접기
- 중간 상태 재인식과 횟수가 제한된 복구 상태기계
- 양팔 도달성, 관절 한계, 상호 충돌과 작업대 충돌 검사
- plan-only, validate-only, supervised-once 순서의 실제 동작 승격
- 실행별 perception, plan, command, measured feedback, 결과 artifact

## 초기 범위 밖

- 매듭이 생긴 수건 또는 심하게 뒤집혀 topology 복원이 불가능한 상태
- 다른 물체 아래에 깔린 수건과 여러 장이 서로 얽힌 상태
- 작업대 밖에서 시작하거나 카메라 시야를 벗어난 상태
- 크기·재질이 알려지지 않은 임의의 의류와 범용 빨래 접기
- 다림질, 세탁, 분류, 적재와 서랍 수납
- 학습·검증되지 않은 policy의 직접 모터 제어
- 무한 반복 또는 제한 횟수를 넘는 자동 실제 동작 재시도

이전 펜 연속 동작과 단일 팔 데모는
[동결 저장소](https://github.com/Anhyeonseo/Bimanual-Pick-And-Place)에만
보존한다. 현재 캔 코드는 강체 인식·파지와 양팔 기반을 검증한 선행 실험이며
최종 완료 조건에는 포함하지 않는다.

## 완료 정의

서로 다른 초기 구김 상태 30회에서 전체 성공률 90% 이상을 달성하고, 최종
형상이 아래 조건을 모두 만족하면 v1 완료로 본다.

- 최종 대응 모서리 평균 오차 25 mm 이하
- 목표 정사각형 대비 외곽선 IoU 0.85 이상
- 두 접힘선의 평균 위치 오차 20 mm 이하
- 수건 낙하, 작업대 이탈, 충돌과 비명령 동작 0회
- 동일 실패의 무한 반복 0회
- 모든 실패가 안전 정지와 재현 가능한 진단 artifact를 남김

300 mm 한 변은 사용자가 확정한 nominal 규격이다. 실제 side tolerance, 두께,
질량과 재질은 R0에서 독립 측정해 task contract에 증빙과 함께 승격한다. 그
전까지 nominal 규격은 계획·simulation fixture에 사용할 수 있지만 실제 동작
권한의 근거는 아니다.
